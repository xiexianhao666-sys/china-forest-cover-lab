# 中国森林覆盖变化查询 · 交互样品 v0.2

按第一轮界面反馈改为紧凑的查询式页面：移除品牌侧栏和宣传标题；主地图占据主要空间，指标作为图内注释；年度趋势、区域变化比较、两期对比嵌入主图分析面板，并可分别折叠或整体隐藏。图形参考ggplot2常见科研风格，使用坐标轴、灰色网格、Viridis顺序色阶及零点居中的变化色阶；实现仍为浏览器SVG，无须安装R。

这是中国森林覆盖变化项目的界面原型，不是模型运行结果。所有省级及全国曲线数值为固定公式生成的合成数据，界面与导出文件均有标记。

真实参考数值25.09%独立引用自2025年中国国土绿化状况公报，不用于合成地图或曲线。地图仅作展示定位，来源为阿里云DataV公开省级GeoJSON：https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json 。正式研究前需复核地图适用许可、边界和范围。

直接双击dist/index.html即可离线体验。数据和地图均打包在本地，不依赖CDN。无AppEEARS请求、无账号凭据、无远程任务提交。

可操作：选择省份或点击地图/条形图、调整起止年份、切换覆盖和变化模式、播放时间、排序比较、两期对比、导出合成CSV及趋势SVG、查看来源说明。

主要文件：dist/index.html、style.css、app.js、data-core.js、china-data.js。

下一步替换data-core中的演示数据接口，并依据正式数据年份、指标口径和验证状态调整页面。1985等尚未接入的历史记录和2026年不填充伪造研究值。
